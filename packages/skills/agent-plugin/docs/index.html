Figma → kode, dengan BUMA DS

Plugin bspace-sdlc-skills berisi 13 skill. Isinya mencakup alur fitur dari ide sampai UI jadi: brainstorm intent, rencana komponen DS dan desain di Figma, slicing ke Flutter atau Vue, verifikasi, lalu close. Semua kode yang dihasilkan hanya presentation, tanpa domain, API, atau repository.

Dokumen ini menjelaskan kondisi saat ini (as-is). Sumber kebenarannya ada di plugins/bspace-sdlc-skills/skills/*/SKILL.md. Kalau dokumen ini berbeda dengan SKILL.md, yang berlaku SKILL.md.

Cara mulai

START · E2E

Fitur baru dari ide

Belum ada intent atau node Figma. Mulai dari router: discover, brainstorm, Blueprint (Gate B), lo-fi wireframe + approval, design reference-first (C1, G2), FTSD (F1), API (F2), platform slice, run-verify, lalu close.

→ using-bspace-sdlc

START · DIRECT

Screen Figma, dengan atau tanpa FSD

Designer butuh screen di Figma. Pakai FSD/intent kalau ada, atau isi brief singkat. Designer tentukan referensi, file, page, dan posisi frame.

→ figma-generate-screen

START · DIRECT

Flutter dari node Figma

Intent/design gate sudah ada, atau task hanya implementasi UI. Langsung slice; skill ini memanggil resolusi component, asset, fidelity, lalu gate output.

→ flutter-slice-screen

START · DIRECT

Vue dari node Figma

Target app standalone Vue sudah jelas. Langsung inventory, plan, human gate, generate, validate, dan lint.

→ vue-slice-screen

START · TARGETED

Perbaikan satu masalah

Sudah tahu masalahnya: component mismatch, asset rusak, fidelity turun, atau runtime overflow. Panggil skill repair langsung; tidak perlu mengulang E2E.

→ component · asset · fidelity · run-verify

WRAPPER · MULTI-UNIT

Banyak section, frame, atau task

Tambahkan model eksekusi SDD di atas route mana pun. Worker fresh, brief/report file, gate eksternal, shared file satu writer.

→ subagent-driven-development

RESUME

Melanjutkan pekerjaan

Baca artefak terakhir di disk. Router memakai gate pertama yang gagal; direct skill memakai prerequisite page dan output contract.

→ router atau skill terakhir yang belum pass

Peta skill

13 skill, 8 kelompoknama skill = nama folder
stakeholder-intake
intake · sebelum P0/P1

Menormalisasi brief, Excel, notulen, SOP, chat, atau link menjadi intake.md + manifest.yaml dengan source ID.

using-bspace-sdlc
router · fase 1–5

Pintu masuk fitur baru: brainstorm → intent.md → rencana komponen → desain Figma + prototype → slice → close. Navigasinya berdasarkan file di disk.

wireframe-lofi
wireframe · gate wajib

Menetapkan screen, state, field, CTA, dan flow dalam grayscale sebelum hi-fi Figma dan approval stakeholder.

figma-generate-screen
design · P3 atau mandiri

Generate screen apa pun di Figma dengan BUMA DS. Sumber adaptif: FSD → intent → brief singkat. Designer memilih referensi dan lokasi (file, page, posisi); AI tidak membuat page sendiri.

blueprint-ftsd
dokumen · P0–P4b

Scaffold Blueprint (FSD) dan FTSD BUMA dari brainstorm, sekali. Setelah itu docx milik analyst; AI baca snapshot, usul lewat Comment, gate dari tanggal approval, API contract openapi.yaml.

flutter-slice-screen
Flutter · utama

Mengubah node Figma menjadi screen Flutter yang bisa dijalankan. Bertindak sebagai orchestrator, mengirim satu worker per section, dan memakai gate --check.

flutter-match-component
Flutter · langkah 5

Mencocokkan node Figma ke class BUMA DS lengkap dengan props-nya. Urutannya: Code Connect, Inner wrapper, tangga eskalasi, lalu gotcha.

flutter-resolve-assets
Flutter · langkah 5

Mengubah ikon, gambar, dan vektor menjadi file asset. Aturan pilih SVG atau PNG, cek isi file di disk, dan larangan kotak placeholder.

flutter-verify-fidelity
Flutter · langkah 8

Memberi skor render Flutter terhadap Figma (geometri lalu piksel) lewat diff_renders.py, dengan loop perbaikan sampai pass atau STOP.

flutter-run-verify
Flutter · langkah 9

Render test headless di 4 lebar layar plus kasus notch dan text scale 1.3, lalu flutter run di device yang tersedia dengan auto-fix.

vue-slice-screen
Vue · utama

Mengubah node Figma menjadi screen Vue (app standalone). Mencakup inventory, coverage, human gate, dan validate-slice.sh.

vue-resolve-assets
Vue · langkah 12

Mengubah gambar dan ilustrasi non-ikon menjadi file di src/assets/<kategori>/ dan memvalidasi isinya.

subagent-driven-development
eksekusi · selalu

Model eksekusi untuk pekerjaan multi-unit: satu worker dengan konteks baru per unit, brief dan report berupa file, gate berupa script.

Artefak di disk

stakeholder-input/<feature>/

intake.md, manifest.yaml, dan optional sources/.

intent/<ID>-<slug>/

intent.md, wireframe.md, design.md, close.md, plus intent/constitution.md (dibuat sekali per repo). Ditulis oleh using-bspace-sdlc.

specs/<ID>-<slug>-<DD_MM_YYYY>/

Flutter: spec.md, plan.md, renders/, work/, tidak ada file lain. Hanya work/iter/*/score.json yang di-commit.

specs/<ID>-<screen-name>/

Vue: spec.md dan plan.md (Inventory, Coverage, Component/Asset decisions, Progress).

lib/features/<f>/presentation/

Flutter: <screen>.screen.dart, widgets/<screen>_content.dart, dan satu widget per section.

*.vue

Vue: screen tipis, <Screen>Content.vue, dan satu <Screen><Section>.vue per section.

assets/images/<kategori>/

Flutter (ditambah satu baris di pubspec.yaml kalau kategorinya baru). Vue: src/assets/<kategori>/.
