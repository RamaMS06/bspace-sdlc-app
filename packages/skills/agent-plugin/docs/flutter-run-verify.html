flutter-run-verify

Membuktikan screen Flutter benar-benar render: headless multi-viewport dulu, lalu runner nyata bila tersedia. Menangkap overflow, infinite constraints, safe-area overlap, large text, missing asset, native build, plugin, launch crash, dan debug-console exception. Bukan skill untuk menulis feature atau business logic.

Route contractCALLED BY FLUTTER SLICE · DIRECT RUNTIME CHECK

Triggerflutter-slice-screen sudah pass --check; user meminta cek runtime/device; atau router melihat run: belum ada.

Contractheadless wajib · device setelahnya
  • PASS (headless): render test exact screen hijau di semua viewport, log tersimpan, zero exception.
  • Runner nyata menambah bukti pod/gradle, platform plugin, launch, dan console. Tidak ada device → run: skipped (no device), bukan blocker headless.
  • Tooling hilang atau screen tidak reachable → BLOCKED, tidak disamarkan sebagai pass.

Langkah

1Locate dan preflight

  1. Package root = nearest pubspec.yaml. Jalankan SDK runner sesuai .fvmrc DS; jangan memakai SDK lebih baru.
  2. Jalankan validate_output.py --check <feature-dir> dulu. Gagal = stop, jangan build.
  3. flutter pub get. Dengan ios/, jalankan flutter build ios --config-only --no-codesign; Podfile.lock stale/missing → pod install --repo-update.
  4. flutter analyze --no-fatal-infos; fix error dan lint yang disebabkan slice. Error pre-existing di luar target dicatat, bukan diperbaiki.

2Render test persistent

Satu file <screen>_render_test.dart per screen, terpisah dari fidelity/component tests. Capture output ke log. Ukuran harus real viewport, bukan hanya designSize.

for (final logical in const [Size(320, 568), Size(390, 844), Size(393, 852), Size(430, 932)]) {
  testWidgets('renders clean at $logical', (tester) async {
    tester.view.devicePixelRatio = 3.0;
    tester.view.physicalSize = logical * 3.0;
    addTearDown(tester.view.reset);
    await tester.pumpWidget(/* same app root + ScreenUtilInit */);
    await tester.pumpAndSettle();
    expect(tester.takeException(), isNull);
  });
}

Tambahkan FakeViewPadding top 59/bottom 34 dan TextScaler.linear(1.3). Semua RenderParagraph harus didExceedMaxLines == false, kecuali truncation Figma yang eksplisit. --check membutuhkan dua API ini.

3Definition headless

Green berarti takeException() null dan captured log zero matches. Jalankan exact test file, bukan directory test. PASS (headless) membuktikan layout, safe area, text scale, dan asset load secara headless; native plugin tetap menunggu device.

4Runner nyata

  1. flutter devices --machine; pilih mobile runner yang sudah hidup. Jika perlu boot existing iOS simulator atau Android emulator. Tidak ada runner sama sekali → skip.
  2. flutter run -d <id> --route <screen route>; simpan output ke build/run-verify/run.log; tunggu first frame + 15 detik lalu quit.
  3. Grep EXCEPTION CAUGHT, overflowed, Unhandled Exception, Xcode/Gradle failure, plus runtime patterns. Warning Xcode/Gradle dicatat sekali, tidak difix.
  4. Auto-fix maksimal 3 ronde, fresh flutter run setiap ronde. Tetap error → run: BLOCKED <first error>.

5Fix yang diizinkan

Boleh: Dart error di slice; overflow lalu re-score; pub get/upgrade dalam DS constraint; direct dependency; pod install; naikkan Podfile minimum iOS ke DS minimum. Tidak boleh: dependency_overrides, ubah Flutter pin/DS ref, --major-versions, // ignore:, melemahkan test, edit di luar slice selain pubspec.yaml/Podfile, hand-edit project.pbxproj.

Untuk overflow: Expanded/Flexible pada bounded Flex; SizedBox hanya jika Figma menentukan extent; Intrinsic* hanya bila sibling perlu berbagi extent. Jangan hardcode ukuran yang tidak ada di Figma.

6Reachability dan screenshot

Screen harus benar-benar di layar, via deep link, navigation nyata, atau temporary initial-location edit yang dikembalikan dan dilaporkan. Simpan screenshot runner di specs/<ID>-.../renders/run-<runner>.png. Screenshot harus menunjukkan target, semua section, icon/image graphic nyata, tanpa blank atau shortened region.

Grepping runtime errors

grep -niE 'EXCEPTION CAUGHT BY|A RenderFlex overflowed by|BoxConstraints forces an infinite|unbounded height|unbounded width|Incorrect use of ParentDataWidget|Unable to load asset|setState\(\) called during build|Failed assertion|Another exception was thrown|RenderBox was not laid out|Vertical viewport was given unbounded height|Cannot hit test a render box' run.log

Definition of done

Render test hijau pada empat viewport + safe-area/text-scale, exit 0, log bersih. Untuk setiap runner: first frame, target reachable, post-navigation grep bersih, screenshot tersimpan, dan file edit serta residual noise dilaporkan.
