flutter-verify-fidelity

Audit screen Flutter terhadap node Figma dengan pasangan screenshot per section, metadata geometry, render test, dan pixel diff. Prosa "sudah mirip" bukan pass. Ground truth selalu Figma MCP, bukan Dart yang sedang diaudit.

Route contractCALLED BY SLICE · DIRECT AUDIT
BagianAs-is
Triggerflutter-slice-screen selesai generate section; user mengatakan screen terlihat berbeda dari Figma.
PrasyaratDart sudah ada, render test/harness tersedia, Figma metadata + screenshot, pair render/layout; plan.md bila dalam slice.
MemanggilPerbaikan bisa kembali ke match-component atau resolve-assets; bukan pengganti run-verify.
Outputscore.json, diff.png, verifier report, history; exit 0/1/4/5.
NextScore pass → flutter-run-verify. Exit 4 → NEEDS_CONTEXT dan developer context baru.
Definition of passgeometry → pixels → fix → re-render
  • Geometry: setiap node keyed rect ±1px; text top/height ±2px; tidak ada geometry error.
  • Pixels: YIQ pixel diff; anti-alias 1–2px diabaikan; mask hanya untuk alasan Figma yang nyata.
  • Pass: section fidelity ≥ 98%, setiap node ≥400px² fidelity ≥ 90%, exit 0.
  • Setiap section punya render pair dan score.json. Tidak ada score di disk = belum diaudit.
  • Skill ini tidak menggantikan flutter-run-verify; runtime, safe area, text scale, pod/gradle, dan device tetap wajib diverifikasi.

Langkah

1Siapkan pair

Satu section memakai Figma width dan tinggi alami section; jangan memasang SizedBox setinggi Figma karena itu menyembunyikan overflow. Pump dengan app ScreenUtilInit nyata, font DS loaded, animation off, sample data Figma. Simpan golden dan work/layout-<id>.json lewat writeLayout. Figma PNG harus hasil get_screenshot scale 1.

Satu section: figma.png/render.png. Banyak section: section-<id>-figma.png/section-<id>.png, sesuai urutan sibling.

2Score

python3 <flutter-slice-screen>/scripts/diff_renders.py <slice-dir> <node-id>

Script menolak render yang lebih tua dari widget file, memeriksa geometry dahulu, lalu pixel diff. Setiap Key('<node-id>') dibandingkan dengan box metadata; setiap TEXT dibandingkan dengan paragraph layout. Hasil menulis work/iter/<id>/{render,layout,diff,score}.*; hanya score.json di-commit.

3Verify dan fix

Jika target node baru gagal, verifier fresh menulis work/section-<id>-verify.md dengan baris <element> — Figma <value> vs Flutter <value>. Score berikutnya exit 5 sampai report lebih baru dari score terakhir dan menyebut semua node gagal baru.

  1. Struktur: geometry, node missing/extra, order, axis.
  2. Colour dan typography dari variable/context tersimpan.
  3. Detail dan visual kecil.

Progress berarti fidelity naik ≥0.5 atau geometry errors berkurang. Re-render dan score setiap fix.

4Stop guard

Tidak ada batas ronde untuk score gate. Stop hanya setelah dua render berurutan tanpa progress dan verifier NEEDS_CONTEXT, atau empat render tanpa progress saat semua beda sudah ditelusuri. Exit 4: laporkan geometry errors, node <90%, diff terakhir, dan history. Lanjut hanya setelah konteks baru dengan:

python3 <flutter-slice-screen>/scripts/diff_renders.py <slice-dir> <node-id> --continue

Jangan hapus score.json; Stop hook memblokir akhir turn bila score gagal tanpa stop.

5Completeness dan layout

  • Fresh get_metadata, recurse nested instance, pastikan semua node visible dirender atau punya alasan non-rendering.
  • Parent mapped tidak menutup badge/icon/label/vector child. Dekorasi tetap asset nyata.
  • Figma sibling order = Dart order. flex-row = Row; flex-col = Column; fill = Expanded/Flexible; hug tidak diberi width paksa.
  • Teks verbatim; tidak ada maxLines/overflow kecuali Figma truncate. Setiap DS component di-assert dengan find.byType; setiap string dengan find.text.
  • Repeated component mengambil nilai dari node masing-masing. Chart memakai data Figma nyata, bukan synthetic.

6Harness wajib

Copy verbatim assets/test-support/fidelity_harness.dart ke test/support/fidelity_harness.dart; jangan edit atau definisikan ulang helper. Harness menyediakan loadDsFonts, pumpDs(frameWidth:, sectionWidth:), dan writeLayout. frameWidth harus sama dengan root Figma; jangan pakai designSize aplikasi seperti 412/360.

setUpAll(loadDsFonts);
await pumpDs(tester, const Screen(), frameWidth: 393, sectionWidth: 361);
await expectLater(find.byKey(const Key('render')), matchesGoldenFile('...'));
writeLayout(tester, '.../work/layout-<id>.json');

Composed screen
