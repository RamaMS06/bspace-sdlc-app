using-bspace-sdlc

Pintu masuk project BUMA, dari discovery sampai UI jadi. P0 Discover selalu wajib: tanpa sdlc/project.md, router tidak boleh membuat intent.md. Setelah discovery, project memakai workspace yang sama untuk intent, Blueprint/FSD, FTSD, API contract, design, slice, verify, dan close.

Gate one-liner

Dijalankan di intent/<ID>-<slug>/ (bash/zsh).

# hash intent: baris approval dibuang, jadi approve tidak membuat pin basi
grep -vE '^(Wireframe|Status|Approved-by):' intent.md | shasum -a 256 | cut -c1-12
# G1: hasil yang diharapkan 1 / 1 / 0 / 0
grep -c '^Status: approved' intent.md; grep -c '^Approved-by: .\+ [0-9]\{4\}-' intent.md
grep -c '\[NEEDS CLARIFICATION' intent.md; grep -cE '^- Q-[0-9]+' intent.md
# C1: hasil yang diharapkan 1, lalu tanpa output (AC yang belum masuk rencana komponen)
grep -c '^Components-approved-by: .\+ [0-9]\{4\}-' design.md
comm -23 <(grep -o 'AC-[0-9]\+' intent.md | sort -u) <(grep -o 'AC-[0-9]\+' design.md | sort -u)
# D0, C1 reference: jalankan one-liner di skills/figma-generate-screen/SKILL.md §Gate one-liners
# G2: hasil yang diharapkan 1 / 1
grep -c '^Reviewed-by: .\+ [0-9]\{4\}-' design.md; grep -c '^Metadata-hash: [0-9a-f]\{12\}' design.md

Fase

1Brainstorm → intent.md (G1)

  • Template assets/intent-template.md, pertanyaan dari assets/question-bank.md (10 pertanyaan, berurutan). Pertanyaan dilewati kalau PRD, Figma, intent/constitution.md, atau kode sudah menjawabnya.
  • Satu pertanyaan per pesan, tanpa jargon. Contoh: "kalau saldo cuti 0, apa yang terjadi?", bukan "apa AC-nya?".
  • Untuk pilihan, opsi pertama diberi label (Recommended) beserta alasannya. Untuk skenario dan edge case, agent mengusulkan daftar dan user mencentang (multi-select).
  • Playback memakai kata-kata user. Kalau user bilang "setuju", agent menulis Status: approved dan Approved-by. User tidak perlu membuka file sama sekali.

2Design → design.md (C1, G2)

Router memanggil REQUIRED SUB-SKILL figma-generate-screen dalam mode SDLC: sumber = Blueprint/FTSD yang sudah Gate B, design.md di intent/<ID>-<slug>/. Skill itu memegang D0 (referensi + lokasi target, selalu ditanya ke designer), C1, GD2, P1, dan G2. Router hanya menambah hard invariant Blueprint dan cek coverage AC.

3–4Slice dan run-verify

Flutter: flutter-slice-screen --intent … menulis pin **Intent:** <path>@<hash> di spec.md dan memetakan setiap AC (atau N/A: <alasan>). --check gagal kalau ada AC yang belum dipetakan atau pin sudah basi. Setelah itu flutter-run-verify. Vue: masih manual, belum ada pin.

5Close → close.md

Tabel | AC | flutter | vue |, hanya untuk platform yang ada di Platforms:. Setiap sel berisi done, N/A: …, diverged: …, atau manual. Tidak boleh ada sel kosong.
