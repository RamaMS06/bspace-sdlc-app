vue-resolve-assets

Menyelesaikan image dan illustration non-icon dari Figma menjadi asset yang benar-benar shipped Vue. Dipanggil standalone atau dari langkah 12 vue-slice-screen. Tidak berlaku untuk icon kecil yang punya prop/slot UI kit.

Langkah

1Pastikan scope

Cek apakah vector adalah icon kecil yang seharusnya masuk icon="..." atau slot prefix. Jika ya, jangan export. Jika bentuk, warna, dan isi adalah bagian khusus screen, perlakukan sebagai illustration.

2Pilih format dari node

Baca fill/type dari get_metadata. Image fill → rawImages; vector paths/boolean group → svgAssets. Jangan menebak dari nama layer, atau menukar vector menjadi raster.

3Reuse dan tujuan

Cari nama atau visual match di src/assets/ serta subfolder yang sudah ada. Vue tidak punya asset-constants manifest; filesystem itu source of truth. Tujuan legal src/assets/<category>/ atau ekuivalen layout repo. Jika kategori belum ada, buat folder feature/domain; tidak perlu registrasi manifest Vite.

Jangan tinggalkan file di root, src/, specs/, cwd, atau folder sementara. Sweep stray *.svg/*.png/*.jpg sebelum selesai.

4Download dan validasi

URL download_assets temporary. Setelah setiap download, cek file:

  • SVG dimulai <svg/<?xml dan punya drawing element (<path, <rect, <g, <image).
  • PNG/JPG punya magic bytes sesuai extension, bukan HTML/ASCII/empty; ukuran masuk akal terhadap dimensi node.
  • Gagal → hapus file, download ulang sekali. Gagal lagi → gap AS-XX, jangan tinggalkan file buruk.

5Import traceable

Ikuti convention screen existing: import bundler atau plain static path. Contoh:

import heroImage from '@/assets/<category>/hero-banner.svg';
<img :src="heroImage" alt="Hero banner" />

Nama file kebab-case dan binding camelCase mengikuti nama layer Figma. Jangan buat fixture atau asset-constants module.

6Fit, position, accessibility

Match size/position metadata: object-fit: cover|contain, width: 100%, atau position: absolute + inset untuk edge anchor; parent harus position: relative. Setiap <img> punya alt; dekorasi memakai alt="" dan dicatat di AS/Coverage.

7Gap dan self-check

Jika tidak ada reuse atau export gagal dua kali, jangan render solid <div> sebagai pengganti. Tulis row AS-XX gap dengan alasan, dan maksimal comment <!-- TODO(asset-gap): AS-XX --> di site. Untuk setiap non-gap: file ada di src/assets/<category>/, content check lulus, dan import/path muncul di .vue yang mengerjakan row.
