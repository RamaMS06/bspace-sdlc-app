blueprint-ftsd

Scaffold Blueprint (FSD) dan FTSD BUMA dari brainstorm. AI mengisi template sekali (v0.01); setelah itu docx milik analyst, designer, FE, BE dan QA di Word. AI membaca snapshot, usul lewat Comment, dan tidak pernah mengisi tanggal approval.

Route contractP0 → GATE F2 · CLAUDE CODE · CLAUDE.AI · CHATGPT
BagianIsi
TriggerAnalyst mulai Blueprint/FTSD, ada sdlc/project.md, atau revisi docx yang sudah approved.
Memanggilusing-bspace-sdlc §1 Brainstorm (per fitur) dan figma-generate-screen (Design Figma).
OutputBlueprint.docx, FTSD.docx, snapshot .md + media, *.gate.json, openapi.yaml.
NextGate F2 pass → FE slice pakai mock OpenAPI, BE implement dari Source/Logic.
