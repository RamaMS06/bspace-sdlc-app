flutter-resolve-assets

Mengubah layer ikon, gambar, dan vector Figma menjadi asset Flutter nyata. Dipakai saat slicing screen, saat asset menjadi kotak kosong, atau saat path asset salah. Hanya berlaku di repo dengan pubspec.yaml.

Langkah

1Reuse sebelum export

Cari nama layer atau padanan visual di lib/**/constants/ serta folder yang terdaftar pada pubspec.yaml. Jika ada match, pakai path tersebut. Jangan export duplikat.

2Scope ID dan simpan response

Gunakan full id dari get_metadata, termasuk compound id seperti I10306:78999;7712:27567. Sebelum download, grep segmen akhir id di ## Assets dan work/raw/download_assets-*; satu id hanya satu download. Simpan response verbatim ke work/raw/download_assets-<node-id>.json. Field export adalah render whole node, bukan asset.

3Tempat dan dependency

  • Tujuan legal: assets/images/<category>/. Jangan simpan di root, lib/, specs/, cwd, atau renders/.
  • Jika kategori belum ada, buat folder dan tambahkan tepat satu entry di bawah flutter: assets:; additive, jangan reformat file.
  • Jika SVG dan flutter_svg belum ada, tambahkan sesuai constraint screening dan catat di ## Notes.
  • Worker hanya mengusulkan kategori/pubspec; orchestrator yang menulis shared file.

4Validasi on-disk

File tersimpan bukan berarti asset valid. SVG harus dimulai <svg/<?xml dan punya drawing element seperti <path, <rect, <g, atau <image. PNG/JPG harus dilaporkan file sebagai format yang benar dan ukurannya masuk akal. Gagal → hapus, download ulang sekali dengan URL baru. Gagal lagi → catat gap dan jangan tinggalkan file buruk.

head -c 200 <file> | grep -q '<svg\|<?xml' && grep -lq '<path\|<rect\|<circle\|<polygon\|<line\|<g \|<use\|<image' <file>

5Reference traceable

Nama file mengikuti nama layer Figma (snake/kebab); local const mengikuti camelCase. Gunakan SvgPicture.asset atau Image.asset di widget screen-local. Jangan mengubah shared asset-constants; laporkan path baru dan usulan constant sebagai follow-up.

6Fit, position, dan gap

Baca ukuran/posisi dari metadata tersimpan. Asset fill memakai BoxFit.cover/fill atau full width; edge-anchored memakai Stack/Positioned; hug memakai ukuran integer. Asset unresolved tidak boleh menjadi Container, ColoredBox, atau Placeholder. Catat // TODO(asset-gap): <node-id> di site widget dan gap di ## Notes.
