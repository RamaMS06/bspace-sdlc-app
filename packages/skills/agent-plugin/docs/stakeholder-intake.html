stakeholder-intake

Normalisasi input stakeholder menjadi paket kecil yang dapat dilacak sebelum P0/P1. Input boleh brief, Excel, notulen, SOP, chat, atau link.

Output contractSTART · BEFORE P0/P1
stakeholder-input/<feature>/
├── intake.md
├── manifest.yaml
└── sources/        optional originals, unchanged

intake.md dibaca analyst. manifest.yaml menjaga source ID, status, owner, dan jejak arsip.

Rules

1Normalize only

Catat klaim yang didukung source. Setiap klaim mencantumkan SRC-xx; konflik dan pertanyaan terbuka tetap dicatat.

2Keep originals

Source asli tidak diedit. Arsipkan di sources/ bila tersedia; gunakan manifest untuk owner, tanggal, tipe, dan status.

3Hand off

Serahkan ke blueprint-ftsd P0 Discover atau P1 Brainstorm. Skill ini tidak membuat intent.md, Blueprint, Figma, API, atau kode.

Gate

python3 <plugin-root>/skills/stakeholder-intake/scripts/check_intake.py .
  • File dan section wajib ada.
  • Status valid.
  • Semua SRC-xx yang dikutip ada di manifest.
  • Path source lokal ada bila diarsipkan.
Sumber: skills/stakeholder-intake/SKILL.md, assets/intake-template.md, dan assets/manifest-template.yaml.
